# Syvursoft Homepage And Product Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Syvursoft company homepage at `/`, move the current RADex landing page to `/radex`, add dedicated `/mend` and `/adam` pages, and add premium controlled Anime.js motion.

**Architecture:** Keep the existing Next App Router and Tailwind structure. Move page composition into focused route files and add small shared data/components for product navigation and animated homepage sections. Use Anime.js only inside isolated client components and preserve existing Framer Motion sections where they already work.

**Tech Stack:** Next 16, React 19, Tailwind 4, TypeScript, Framer Motion, Anime.js, lucide-react.
